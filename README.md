# Web Node

Proyecto web experimental en Next.js preparado para despliegue en Hostinger con Node.js.

## Estructura
- `/` — página principal
- `/love` — módulo visual independiente

## Desarrollo local
```bash
npm install
npm run dev
```

## Producción
```bash
npm run build
npm start
```

En Hostinger, el comando de build es `npm run build` y el de inicio es `npm start`.
