# Boda Web

Proyecto inicial en Next.js para Hostinger Node.js.

## Rutas
- `/` — portada inicial
- `/love` — página Love original, servida como HTML real para que Safari ejecute JavaScript

## Desarrollo local
```bash
npm install
npm run dev
```

## Producción
```bash
npm run build
npm start
```

En Hostinger, el comando de build es `npm run build` y el de inicio es `npm start`.
